1) 리스크 모드

  • VIX가 급등이면: 포지션 축소/손절 기준 재점검
  • 지수 하락 + 환율 상승 조합이면: 방어주/현금비중 고려
  • Tip: VIX ≥ 20이면 시장 체감 변동성↑

2) 오늘 할 일

  • 전일 대비 상·하위 자산(지수/원자재/크립토) 1개씩 메모
  • 내 포트폴리오 리스크(베타) 점검: 과열 종목 비중 확인
  • Tip: “오늘 한 문장 기록”이 수익화 콘텐츠로 좋아요

3) 콘텐츠 훅 포인트

  • 52주 고점·저점 근처면: “여기서 갈림길”형 제목 강력
  • VIX 급등이면: “공포지수 경고등” 이슈 글로 확장
  • Tip: 그래프 + 3줄 요약 + 체크리스트가 체류시간↑

참고
- S&P 500은 SP:SPX 대신 OANDA:SPX500USD로 통일(위젯 제한 회피).
- 코스피/코스닥/VIX는 GitHub Actions가 만들어주는 /data/*.json을 Chart.js로 직접 그립니다.
- 기간 버튼은 “거래일 기준”으로 대략 슬라이싱(1M≈22, 3M≈66, 6M≈132, 1Y≈264).
- 차트의 점선 2개는 선택 기간 기준 최고/최저(52주 라벨 유지) 라인입니다.
